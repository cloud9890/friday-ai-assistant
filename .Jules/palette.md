## 2025-05-18 - Tactical HUD Icon Button Accessibility
**Learning:** Icon-only buttons and canvas-adjacent controls in futuristic dark HUD interfaces frequently lack explicit ARIA labels and focus indicators, rendering them inaccessible to screen readers and keyboard navigation.
**Action:** Always complement visual HUD icon buttons with descriptive `aria-label` attributes and add standard focus-visible rings matching the HUD primary glow palette.
